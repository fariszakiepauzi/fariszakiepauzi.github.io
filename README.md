# Statistics & Data Analytics Portfolio

A responsive, single-page portfolio starter for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload `index.html` to the root of the repository.
3. Open **Settings → Pages** and select the main branch and root folder if GitHub Pages is not enabled automatically.
4. Save and wait for GitHub Pages to publish the site.

## Personalise before publishing

Search `index.html` for these placeholders and replace them:
- `YOUR-USERNAME`
- `YOUR-EMAIL@example.com`
- `YOUR-LINKEDIN`
- Project repository links

Also:
- Add a resume PDF and link it from the hero section if you want a download button.
- Add screenshots of real charts or dashboards to project cards.
- Remove any tool you cannot confidently discuss in an interview.
- Verify the project descriptions, status, and findings before publishing.
- Do not upload confidential internship, employer, survey, or personal data. Use anonymised examples or public/sample datasets.
